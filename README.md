## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jeevankb-cse/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the local server:**
   ```bash
   npm start
   ```
   Open [http://localhost:3000/portfolio](http://localhost:3000/portfolio) to view the site in your browser.

---

## 📦 Deployment to GitHub Pages

To deploy updates to the live site:

```bash
npm run deploy
```

This runs `npm run build` and automatically pushes the compiled production bundle to the `gh-pages` branch.
